# Color Palette Generator

A simple color palette generator built using HTML, CSS, and JavaScript.

## Features

- Generate random color palettes
- Display HEX color values
- Copy HEX codes to clipboard
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome

## How to Use

1. Open index.html in your browser.
2. Click the Generate Palette button.
3. A new random color palette will be generated.
4. Click the copy icon to copy a HEX color.

## Project Structure

- index.html - Main webpage
- style.css - Styling
- script.js - JavaScript functionality
- README.md - Project documentation
